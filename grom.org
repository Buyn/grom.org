Если это кнопка внутри Reagent/Hiccup, проще всего заменить `:button` на ссылку `:a`.

Было:

```clojure
[:button
 {:class "bg-orange-500 hover:bg-orange-600 text-white px-8 py-4 rounded-lg"}
 (tr :apply)]
```

Сделай так:

```clojure
[:a
 {:href "https://docs.google.com/forms/d/e/1FAIpQLSc2pYrPf7goC92oB5-IFkte5MIXu95Bl6UjhE9g5tOIxWt98w/viewform?usp=header"
  :target "_blank"
  :rel "noopener noreferrer"
  :class "inline-block bg-orange-500 hover:bg-orange-600 text-white px-8 py-4 rounded-lg"}
 (tr :apply)]
```

Что это даёт:

- `:href` — ссылка на Google Form.
- `:target "_blank"` — открывает форму в новой вкладке.
- `:rel "noopener noreferrer"` — хорошая практика безопасности.
- `inline-block` нужен, чтобы ссылка выглядела как кнопка.

Если принципиально оставить именно `:button`, то:

```clojure
[:button
 {:class "bg-orange-500 hover:bg-orange-600 text-white px-8 py-4 rounded-lg"
  :on-click #(js/window.open
               "https://docs.google.com/forms/d/e/1FAIpQLSc2pYrPf7goC92oB5-IFkte5MIXu95Bl6UjhE9g5tOIxWt98w/viewform?usp=header"
               "_blank")}
 (tr :apply)]
```

Но для перехода на внешнюю страницу вариант с `:a` считается более правильным.
***** а если переход на внутренюю?
Если переход внутри твоего SPA (через роутер), тогда использовать `:a` с обычным `:href` не стоит — страница перезагрузится.

Для внутренних переходов нужно вызывать твой роутер через `navigate!`.

Например, если у тебя есть маршрут:

```clojure id="j4wni6" "#/membership" ```

то кнопка будет такой:

```clojure id="m68kic" [:button {:class "bg-orange-500 hover:bg-orange-600 text-white px-8 py-4 rounded-lg" :on-click #(navigate! "#/membership")} (tr :apply)] ```

или как ссылка без перезагрузки:

```clojure id="ldx5a0" [:a {:on-click (fn [e] (.preventDefault e) (navigate! "#/membership")) :class "inline-block bg-orange-500 hover:bg-orange-600 text-white px-8 py-4 rounded-lg"} (tr :apply)] ```

Главное:

### Внешний переход

Используй:

- `:href`.

### Внутренний переход в SPA

Используй:

- `navigate!`.

Тогда всё будет работать без полной перезагрузки страницы, и состояние приложения сохранится.

### Как это работает

Пользователь открывает:

```text
ueava.org
    ↓
Membership
    ↓
Apply for Membership
    ↓
Google Form
```

Заполняет:

- Имя
- Фамилия
- Email
- Телефон
- Страна
- Город
- Статус
- Место работы
- Загрузка диплома/студенческого

Нажимает Submit.

После этого данные автоматически сохраняются.

---

## Куда сохраняются данные

Google Forms автоматически может писать ответы в Google Sheets.

Получается такая схема:

```text
Google Form
      ↓
Google Sheets
```

В таблице будут строки:

| Дата       | Имя  | Фамилия | Email | Телефон |
| ---------- | ---- | ------- | ----- | ------- |
| 12.06.2026 | Иван | Иванов  | ...   | ...     |

Очень удобно.

---

## Куда сохраняются дипломы

Если включить вопрос:

```text
Upload File
```

то файлы сохраняются в Google Drive владельца формы.

Получается:

```text
Google Form
      ↓
Google Drive
      ↓
Дипломы
```

И в таблице появляется ссылка на файл.

Отдельный организационный аккаунт.

# 1️⃣ Самый простой — вставить SVG прямо как hiccup

Открываешь `logo.svg` и копируешь содержимое внутрь компонента.

SVG:

```xml
<svg viewBox="0 0 200 200">
  <g id="logo-text">...</g>
  <g id="puzzle-1">...</g>
  <g id="puzzle-2">...</g>
</svg>
```

в Reagent превращается в:

```clojure
(defn logo []
  [:svg {:viewBox "0 0 200 200"}
   [:g {:id "logo-text"} ...]
   [:g {:id "puzzle-1"} ...]
   [:g {:id "puzzle-2"} ...]])
```

Теперь можно управлять:

```clojure
[:g {:class (when hide-text "hidden")}]
```

или

```clojure
[:g {:class (when highlight "fill-yellow-400")}]
```

---

# 2️⃣ Использовать SVG как React компонент (очень удобно)

Если у тебя сборка через **shadow-cljs / vite / webpack**, можно импортировать SVG как компонент.

Например:

```clojure
(ns app.logo
  (:require ["./logo.svg" :default Logo]))
```

и использовать:

```clojure
[:> Logo {:class "w-40"}]
```

Но тут есть нюанс:
ты **не сможешь менять внутренние элементы SVG**, только весь SVG целиком.

```clojure

(defn logo []
  [:svg {:viewBox "0 0 1133.86 351.36"}
   [puzzle-1 {:highlight true}]
   [puzzle-2]

   [:text {:class (when hide-text "hidden")} "UEAVA"]])
```

Теперь ты можешь **подсвечивать отдельные пазлы**, скрывать текст или менять части логотипа на лету через `Reagent atoms`.

## 💎 что ты хочешь

- `dt ≤ 1000 ms` → **100 ms**
- `dt ≥ 3000 ms` → **700 ms**

---

## ✨ решение — линейная интерполяция (lerp)

формула простая:

```
t = (dt - min) / (max - min)
duration = minDuration + t * (maxDuration - minDuration)
```

---

## 🔥 код

```clojure
(defn clamp [x min max]
  (-> x (max min) (min max)))

(defn lerp [a b t]
  (+ a (* (- b a) t)))

(defn compute-duration [last-ts]
  (let [dt (- (now) last-ts)
        min-dt 1000
        max-dt 3000
        min-duration 100
        max-duration 700

        ;; normalize dt to 0..1
        t (-> (/ (- dt min-dt)
                 (- max-dt min-dt))
              (clamp 0 1))]

    (js/Math.round
     (lerp min-duration max-duration t))))
```

---

## 😏 как это ведёт себя

| dt   | duration |
| ---- | -------- |
| 0.5s | 100      |
| 1s   | 100      |
| 2s   | ~400     |
| 3s   | 700      |
| 5s   | 700      |

👉 никаких скачков
👉 только плавная реакция
