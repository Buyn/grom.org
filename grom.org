### Вариант 1. Самый простой — внешний сервис

Форма на сайте не отправляет письма сама, а добавляет email в сервис рассылок:

- [Brevo](https://www.brevo.com?utm_source=chatgpt.com)
- [MailerLite](https://www.mailerlite.com?utm_source=chatgpt.com)
- [Mailchimp](https://mailchimp.com?utm_source=chatgpt.com)

Схема:

```
SPA
 ↓
POST /api/newsletter
 ↓
Backend
 ↓
Brevo API
 ↓
Список подписчиков
```

А дальше в панели сервиса:

- создаёшь письмо;
- нажимаешь "Send";
- или настраиваешь автоматические цепочки.

Для небольшой ассоциации это обычно лучший путь.

### Вариант 2. Свой сервер + своя рассылка

```clojure

 {:on-submit subscribe!}
 ...]
```

Отправляет:

```json
{
  "email": "user@example.com"
}
```

На сервер.

Сервер сохраняет:

```sql
newsletter_subscribers
----------------------
id
email
created_at
confirmed
unsubscribe_token
```

Потом отдельный скрипт:

```bash
send-newsletter.sh
```

или cron-задача:

```bash
0 10 * * * send-newsletter
```

берёт список адресов и рассылает письма через SMTP.

Никакого собственного сервера.

**Все три сервиса — Brevo, MailerLite и Mailchimp — это популярные платформы для email-маркетинга.** Они подходят для рассылок, автоматизаций, форм подписки и лендингов. Но сильно отличаются по ценообразованию, лимитам, удобству и дополнительным функциям.

### Краткое сравнение (на 2026 год)

| Параметр              | **Brevo** (ex-Sendinblue)                          | **MailerLite**                              | **Mailchimp**                              |
|-----------------------|----------------------------------------------------|---------------------------------------------|--------------------------------------------|
| **Бесплатный план**  | Да, очень щедрый: **300 email/день** (~9000/мес), **до 100 000 контактов** | Да: **до 500 подписчиков**, **12 000 email/мес** | Да, но ограниченный: **до 250 контактов**, **~500 email/мес** |
| **Ценообразование**  | По количеству отправленных email (не по контактам). Гибко для больших списков | По количеству подписчиков + план          | По количеству контактов + план (дороже)   |

| **Удобство**         | Хорошее, но чуть больше функций → кручевая кривая обучения | Самое простое и интуитивное               | Удобное, но интерфейс перегружен          |

| **Дополнительно**    | SMS, transactional emails, CRM, встроенный чат    | Монетизация (платные подписки), формы      | Интеграции, AI, landing pages, реклама    |

### Бесплатные планы — подробнее
- **Brevo** — один из самых щедрых. Можно хранить огромный список контактов и отправлять ежедневно. Идеально для старта и тестов. Есть брендирование (логотип Brevo).
- **MailerLite** — отлично для малого объёма. 12k писем в месяц при 500 подписчиках — хватает для регулярных рассылок.
- **Mailchimp** — самый жёсткий бесплатный план сейчас (после сокращений). Подходит только для очень маленьких списков.

**Вывод по бесплатным:** Если у вас растёт список или вы отправляете часто — **Brevo** выигрывает. Для красивых писем с малым объёмом — **MailerLite**.

### Платные услуги и тарифы (примерные цены на 2026)
Цены зависят от объёма и могут меняться — проверяйте на сайтах.

- **Brevo**:
  - Starter / Standard: от ~$9–25/мес за 5–20k email.
  - Гибкая модель: платишь за реально отправленные письма.
  - Допы: удаление брендинга, приоритетная поддержка, расширенный CRM, SMS-кредиты.

- **MailerLite**:
  - Growing Business: от $10/мес.
  - Advanced: от $20/мес.
  - Неограниченные email в платных планах, больше автоматизаций, пользователей, A/B-тесты и т.д.

- **Mailchimp**:
  - Essentials: от $13/мес.
  - Standard: от $20/мес.
  - Premium: от $350+ (для больших объёмов).
  - Дороже при росте списка контактов. Много доп.функций (AI, продвинутые интеграции).

### Основные различия
- **Brevo** — лучший по цене/качеству для большинства, особенно если нужны SMS или CRM. Меньше ограничений на контакты.
- **MailerLite** — самый дружелюбный и дешёвый для малого бизнеса/блогеров. Отличные шаблоны и простота.
- **Mailchimp** — самый известный, с кучей интеграций и "корпоративным" видом. Но дороже и с жёсткими лимитами на старте.

**Рекомендация:**
- Маленький список + красота → **MailerLite**.
- Растущий бизнес, много контактов, multichannel → **Brevo**.
- Большой бренд + интеграции → **Mailchimp**.

### Что нужно для автоматизации подписки
1. **Форма на сайте** (в SPA: React/Vue/Svelte и т.д.) → собирает email (и другие данные).
2. **Отправка данных** на сервис:
   - Через **API** (самый надёжный и гибкий способ).
   - Embed-форму (HTML + JS).
   - Webhook / события.
3. **Автоматизация внутри сервиса**:
   - Добавление в список/группу.
   - Double Opt-In (подтверждение по email).
   - Welcome-серия, триггеры (например, "добавлен в список → отправить серию писем").

### Сравнение по API и интеграции для SPA

| Сервис       | API качество                  | Как реализовать подписку в SPA                          | Автоматизации после подписки                  | Плюсы для SPA                          | Минусы                          |
|--------------|-------------------------------|---------------------------------------------------------|-----------------------------------------------|----------------------------------------|---------------------------------|
| **Brevo**   | Отличный REST API + SDK (Node.js, PHP и др.) | POST `/contacts` или `/subscribers` с API-ключом       | Автоматизации по "contact added to list" + transactional | Гибкий, transactional emails, CRM     | Чуть больше настроек            |
| **MailerLite** | Хороший современный REST API | POST `/subscribers` (с group_id)                       | Автоматизации по "joins group"                | Простой, красивые формы               | Ограничения на бесплатном       |
| **Mailchimp** | Полноценный Marketing API    | POST `/lists/{list_id}/members`                        | Journeys / Automations                        | Много интеграций                      | Дороже при росте, строже с API  |

**Все поддерживают:**
- Double Opt-In.
- Custom fields (имя, телефон и т.д.).
- Webhooks (уведомления о подписке/отписке).
- Rate limits (нужно учитывать в коде).

### Конкретная реализация для SPA (пример на JavaScript/Fetch)

#### 1. Brevo (рекомендую для большинства)
```javascript
// В компоненте формы (React/Vue и т.д.)
async function subscribe(email, name) {
  const response = await fetch('https://api.brevo.com/v3/contacts', {
    method: 'POST',
    headers: {
      'api-key': 'YOUR_BREVO_API_KEY',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      email: email,
      attributes: { FIRSTNAME: name },
      listIds: [2],           // ID вашего списка
      updateEnabled: true     // обновлять если уже есть
    })
  });

  if (response.ok) {
    // Запустить welcome-автоматизацию в Brevo
    alert('Подписка оформлена!');
  }
}
```
- В Brevo настройте Automation: **"Contact added to list" → Send welcome email series**.

#### 2. MailerLite
```javascript
async function subscribe(email) {
  await fetch('https://connect.mailerlite.com/api/subscribers', {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer YOUR_MAILERLITE_API_KEY',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      email: email,
      groups: ["your_group_id"]
    })
  });
}
```
- Автоматизация: "Joins group" → welcome sequence.

#### 3. Mailchimp
```javascript
async function subscribe(email) {
  await fetch(`https://YOUR_SERVER.mailchimp.com/3.0/lists/YOUR_LIST_ID/members`, {
    method: 'POST',
    headers: {
      'Authorization': 'Basic ' + btoa('anystring:YOUR_API_KEY'),
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      email_address: email,
      status: 'subscribed'   // или 'pending' для double opt-in
    })
  });
}
```
- Используйте Journeys для автоматизаций.

### Дополнительные механики (не только API)
- **Embed-формы** — вставляете готовый HTML/JS от сервиса. Работает, но меньше контроля в SPA.
- **Zapier / Make** — no-code: форма → сервис (хорошо для теста).
- **Готовые плагины** — если SPA на Next.js / Nuxt и т.д., есть примеры интеграций.

```clojure
[:button

 (t :footer/news-button)]
```

Тогда:

- поле email в футере убирается;
- пользователь нажимает кнопку;
- MailerLite открывает своё popup-окно;
- подписка происходит внутри него.

## ✨ решение — линейная интерполяция (lerp)

формула простая:

```
t = (dt - min) / (max - min)
duration = minDuration + t * (maxDuration - minDuration)
```

---

## 🔥 код

```clojure
(defn clamp [x min max]
  (-> x (max min) (min max)))

(defn lerp [a b t]
  (+ a (* (- b a) t)))

(defn compute-duration [last-ts]
  (let [dt (- (now) last-ts)
        min-dt 1000
        max-dt 3000
        min-duration 100
        max-duration 700

        ;; normalize dt to 0..1
        t (-> (/ (- dt min-dt)
                 (- max-dt min-dt))
              (clamp 0 1))]

    (js/Math.round
     (lerp min-duration max-duration t))))
```
