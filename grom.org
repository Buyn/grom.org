SVG:

```xml
<svg viewBox="0 0 200 200">
  <g id="logo-text">...</g>
  <g id="puzzle-1">...</g>
  <g id="puzzle-2">...</g>
</svg>
```

в Reagent превращается в:

```clojure
(defn logo []
  [:svg {:viewBox "0 0 200 200"}
   [:g {:id "logo-text"} ...]
   [:g {:id "puzzle-1"} ...]
   [:g {:id "puzzle-2"} ...]])
```

Теперь можно управлять:

```clojure
[:g {:class (when hide-text "hidden")}]
```

или

```clojure
[:g {:class (when highlight "fill-yellow-400")}]
```

## ✨ решение — линейная интерполяция (lerp)

формула простая:

```
t = (dt - min) / (max - min)
duration = minDuration + t * (maxDuration - minDuration)
```

---

## 🔥 код

```clojure
(defn clamp [x min max]
  (-> x (max min) (min max)))

(defn lerp [a b t]
  (+ a (* (- b a) t)))

(defn compute-duration [last-ts]
  (let [dt (- (now) last-ts)
        min-dt 1000
        max-dt 3000
        min-duration 100
        max-duration 700

        ;; normalize dt to 0..1
        t (-> (/ (- dt min-dt)
                 (- max-dt min-dt))
              (clamp 0 1))]

    (js/Math.round
     (lerp min-duration max-duration t))))
```
